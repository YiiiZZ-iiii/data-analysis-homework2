## 练习二 · 脏数据清洗 + 入库 + 分析（重点在「洗」不在「抓」）

- **网址**（任选其一）：维基百科英文/中文「各国人口列表」。
- **提取字段**：国家名 + 人口数值。
- **脏在哪**：千分位逗号 `1,463,865,525`、脚注 `255,219,554[3]`、不可见空格（NBSP/窄空格）做千分位、单位混杂 `≈341.8 million`、缺失值（空单元格）。
- **清洗→入库→分析**：
  1. 去脚注、去千分位、识别单位（billion/million/亿/万）并换算；
  2. 按类型分类存入 SQLite：`name TEXT`、`pop INTEGER`、`pct REAL`；
  3. 读出后排序、求和、取前十；缺失值按 NULL 处理、不参与排名。
- **结果**：201 行有效数据入库，数字列可正常计算，排名表如下。

## 练习三 · 动态页：内容「等一等才出现」

- **网址**：`quotes.toscrape.com/js`（JS 填充）、`quotes.toscrape.com/scroll`（无限滚动）。
- **为什么直接 requests 拿不到**：服务器第一次返回的 HTML 是「空房间」，名言是后来由 JavaScript 填进去的；浏览器会执行 JS，Python 的 `requests` 不会。
- **应对策略（用「直接找数据接口」这条更聪明的路）**：
  - `/js`：名言数据就嵌在页面 `<script>` 的 `var data = [...]` JSON 里，直接解析出来；
  - `/scroll`：数据来自接口 `/api/quotes?page=N`，直接请求该接口拿 JSON。
- **结果**：`/js` 10 条、`/scroll` 100 条（名言内容 + 作者）。

```bash
python3 代码/项目三_动态页_quotes.py
```
